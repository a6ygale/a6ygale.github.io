Grating lobes in phased arrays

When element spacing is too large relative to wavelength, the array factor can develop additional maxima that enter visible space. Steering changes where those replicas appear.

EM / 02

Fourier transform & far-field patterns

Under appropriate scalar and far-field approximations, the angular field distribution is related to the spatial Fourier transform of the aperture field distribution.

Efar(kx, ky) ∝ ℱ{Eap(x,y)}

RF / 03

Array factor from element phase

The total field is a coherent sum of element contributions. In a uniform linear array, element spacing and phase progression control the direction of constructive interference.

AF(θ) = Σ wn ej n ψ(θ)
